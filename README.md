# BUSIAN V1 GitHub Foundation

Upload the whole folder to your GitHub repository, keeping `index.html` at the root.

Included:
- Public landing page
- Marketplace/product cards
- Customer entry
- Merchant onboarding
- Field Agent onboarding
- Rider onboarding
- Partner onboarding
- Role-based workspace prototypes
- Product adding workflow
- Local price/product lifecycle concepts
- Responsive mobile-first design

This is a frontend prototype. Real authentication, Supabase, M-PESA/Daraja, payment verification, settlements, commissions, audit logs and production security belong in the backend. Never place M-PESA secrets or Supabase service-role keys in frontend JavaScript.

Next phase: connect the defined screens to Supabase and implement the real lifecycle records and permissions.
